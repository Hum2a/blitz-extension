# Changelog

All notable changes to the Blitz Chrome extension are documented here.

- Phase 3: Workday support, match score visualization, bulk job queue

- Local jsPDF bundle (MV3 CSP compliant)

- Phase 2: LinkedIn Easy Apply, Indeed, PDF generation, license worker
- Application tracker with CSV export and notes

## [1.0.0] - 2026-05-16

- Phase 1: Greenhouse MVP — AI tailoring, review panel, form fill, free tier
